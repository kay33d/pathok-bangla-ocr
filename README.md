## Overview

PATHOK (পাঠক, "reader") is an encoder–decoder OCR framework that recognizes both **Bangla
handwritten text** and **Bangla scene text** (signboards, posters, number plates) within a
single pipeline. The core research question is how the choice of **image encoder** and
**tokenization strategy** affects recognition of Bangla, whose script is built from
graphemes — vowels, consonants, and consonant conjuncts, optionally combined with vowel or
consonant diacritics.

The pipeline pairs one of two visual encoders with a Transformer decoder:

| Component | Options evaluated |
|---|---|
| Encoder | ResNet-18 (CNN) · TrOCR ViT encoder (Transformer) |
| Decoder | Transformer decoder (autoregressive) |
| Tokenizer | **Grapheme** · Character · Byte Pair Encoding (BPE) |

## Key results

Evaluated on the **BnHTRD** handwritten word test set (6,614 samples), with cross-dataset
evaluation on **IIIT-Indic (Bengali)**:

| Configuration | Word Accuracy | CER | WER |
|---|---|---|---|
| **TrOCR + Grapheme (best)** | **92.21%** | **2.52%** | **7.79%** |

- The TrOCR ViT encoder consistently outperforms the ResNet-18 encoder.
- Grapheme tokenization beats character-level tokenization and BPE.
- For scene text, a **three-phase synthetic-to-real training strategy** (initialised from
  the handwritten checkpoint) reaches **72.25% word accuracy / 11.61% CER** on a real
  Bangla scene text test set (1,074 samples, IIIT-Indic STR).

## Repository structure

```
pathok/
  config.py            # Central hyperparameters and paths
  tokenizers.py        # Grapheme, character, and BPE tokenizers
  dataset.py           # BnHTRD / scene-text dataset loading and preprocessing
  metrics.py           # CER, WER, word accuracy
  models/
    encoders.py        # ResNet-18 and TrOCR ViT feature extractors
    decoder.py         # Transformer decoder with cross-attention
    pathok_model.py    # Full encoder–decoder model + greedy decoding
scripts/
  train.py             # Train any encoder × tokenizer combination
  evaluate.py          # Evaluate a checkpoint (CER / WER / word accuracy)
  predict.py           # Run inference on a single image or folder
  generate_scene_text.py  # Synthetic Bangla scene text generation (Phase-1 data)
thesis/
  PATHOK_Thesis.pdf    # Thesis report
```

python -m venv .venv && source .venv/bin/activate

## Usage

Train the best configuration (TrOCR encoder + grapheme tokenizer) on BnHTRD:

```bash
python scripts/train.py --encoder trocr --tokenizer grapheme \
    --data-root data/bnhtrd --epochs 30
```

Evaluate a checkpoint:

```bash
python scripts/evaluate.py --checkpoint runs/trocr_grapheme/best.pt \
    --data-root data/bnhtrd --split test
```

Generate synthetic scene text for Phase-1 scene training:

```bash
python scripts/generate_scene_text.py --corpus data/words.txt \
    --fonts-dir assets/fonts --out data/synth_scene --num-images 50000
```

Recognize an image:

```bash
python scripts/predict.py --checkpoint runs/trocr_grapheme/best.pt --image sample.png
```

## Datasets

| Dataset | Role |
|---|---|
| BnHTRD | Handwritten training/validation/test (word-level crops) |
| IIIT-Indic (Bengali) | Cross-dataset generalisation + real scene text |
| Synthetic scene text | Generated by `scripts/generate_scene_text.py` |

Datasets are **not** included in this repository; download them from their original
sources and point `--data-root` at them.
